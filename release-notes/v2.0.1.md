Battery details are back on macOS 27.

## Fixed

- **Battery capacity.** On macOS 27, Current and Original capacity both showed 100 mAh, because macOS moved where it reports them. ChillMac now finds the real figures, and says "Not reported" if a Mac doesn't provide one.
- **Battery temperature.** macOS 27 stopped reporting it in the usual place, so the Battery panel showed 0°. ChillMac now reads it from the Mac's own battery sensors instead.

Only the Battery panel was affected. Fan control, the menu bar reading and the other panels were accurate throughout.
