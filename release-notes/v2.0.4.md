Setting up fan control now tells you what went wrong instead of quietly doing nothing.

## Fixed

- **Install button that did nothing.** When macOS refused to install the fan helper, ChillMac only wrote the reason to its log, so pressing Install in setup or in the menu looked like a dead button. The reason now appears next to the button. Monitoring was never affected; only fan control was unavailable.
- **Running outside Applications.** When macOS runs ChillMac from the disk image or a temporary copy, the helper can't be installed reliably. ChillMac now spots this and asks you to move it to Applications first.

## Improvements

- **Diagnostics.** Exports now include the fan helper's status and the last install error, so setup problems can be diagnosed from the file alone.
