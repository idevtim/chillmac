If fan control setup was failing with "Operation not permitted", ChillMac can now fix it for you with one password prompt.

## Fixed

- **Fan control setup blocked by an old helper.** ChillMac versions before 1.8.1 installed their fan helper differently, and updating never removed it. That leftover copy made macOS refuse to install the current one. ChillMac now spots it and offers a "Remove old helper" button that asks for your password once, removes it, and sets up fan control. Monitoring was never affected.

## Improvements

- **Diagnostics.** Exports now note whether an old helper is still installed.
