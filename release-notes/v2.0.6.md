Reinstalling the fan helper now works on the first try.

## Fixed

- **"Operation not permitted" when reinstalling the helper.** Reinstall removed the old helper and installed the new one in the same instant, before macOS had finished the removal, so macOS refused it and pressing the button again was the only way through. ChillMac now waits for the removal to finish and retries for a few seconds if macOS is still busy. Fan control and monitoring were otherwise unaffected.
