## Highlights

ChillMac now tells you when a new version is out without interrupting you. A small download badge appears on the menu bar fan, and opening ChillMac shows an Update button right at the top, no trip to Settings needed.

## Added

- **Update badge in the menu bar.** ChillMac checks for new versions every few hours in the background. When one is found, the fan icon gets a small download arrow in its corner. Choosing "Skip This Version" clears it
- **Update button on the main screen.** A card at the top of the popover names the new version and installs it in one click. ChillMac relaunches itself when it's done
- **Install with Homebrew.** `brew install --cask idevtim/tap/chillmac` now works, and Homebrew installs keep updating themselves like any other copy
