# ChillMac 1.9.0 — Stay cool. Stay quiet.

## Cool redesign (silent until needed)

Performance Mode is now **Cool**. Fans stay on **macOS Auto** while the machine is cool — even on Performance intent. ChillMac only takes over with a curve after temperatures cross an engage threshold, and returns to Auto after a release dwell. This removes the old forever floors (including Ultra’s 70% baseline when cool).

| Intent | Engage | Release | Behavior when engaged |
|--------|--------|---------|------------------------|
| Quiet | ≥ 70°C | ≤ 60°C | Gentle curve |
| Balanced | ≥ 65°C | ≤ 55°C | Responsive curve |
| Performance | ≥ 55°C | ≤ 45°C | Steep curve / fast ramp |

`ProcessInfo.thermalState` of **serious** or **critical** also forces engagement.

## Product shape

- Popover leads with **Cool** (on/off + Quiet / Balanced / Perf), then Fans, then a compact System glance.
- Settings primary list is shorter; power-user fan/FPS options live under **Advanced**.
- Visual chrome uses system materials and hierarchical text styles (no custom blue-green Theme skin).

## Migration

Legacy Low / Medium / High / Max / Ultra levels map to Quiet / Balanced / Performance automatically.
