## Highlights

ChillMac 2.0 is a full redesign. The popover now leads with how your Mac is doing, keeps the numbers to one compact list, and replaces the old Performance Mode and per-fan switches with a single Cooling control. Your settings carry over: if Performance Mode was on, you're now on Smart cooling at the same intensity.

This update includes a new fan control helper, so macOS will ask you to allow ChillMac again in System Settings › General › Login Items & Extensions. Monitoring keeps working in the meantime, and later updates go back to one click.

## Fixed

- **Manual fan control on newer Macs.** On some Apple Silicon Macs, including the M4 Max, macOS took a moment to hand over the fans, ChillMac gave up too early, and the fans quietly stayed on automatic. ChillMac now waits for the handover, and if macOS still keeps control, the Cooling card says so.

## Added

- **One Cooling control.** Choose Automatic (macOS runs the fans), Smart (fans follow temperature) or Manual (you set each fan's speed). Smart's levels are now called Quiet, Balanced, Cool and Max.
- **A welcome for new installs.** A short setup window explains the fan control helper before asking for it, then walks through cooling and menu bar options. Reopen it anytime from Settings.
- **New app icon.** The snowflake is replaced by a fan, which also appears in the menu bar.

## Improvements

- **Easier-to-read panels.** Memory, Battery, Temperatures, CPU and Disk each open with a plain-language summary, and temperature sensors are grouped so you can expand only the ones you care about.
- **Simpler Settings.** Fewer sections, clearer wording, and a place to reinstall or remove the fan control helper.
- **Friendlier fan control setup.** Without the helper, ChillMac now explains what it does and what it never touches, instead of showing a warning. Monitoring works either way.
