## Highlights

Fan Sooner (formerly ChillMac) now ships **Cool** — a native menu bar experience with five performance levels including **Ultra**, a throttle-avoidance curve that ramps fans earlier to hold peak clocks under load without spinning at 100% when the machine is cool.

This release also adds **Sparkle in-app updates**: one click downloads, verifies the signature, installs, and relaunches. You'll need to install v1.8.0 by hand one last time if you're coming from a build without Sparkle; every release after that is a single click from Settings or the menu badge.

## New

- **Cool menu redesign** — native NSMenu replaces the popover dashboard; pick Native / Low / Medium / High / Max / Ultra from the menu bar, with thermal status and optional temperature in the status item
- **Ultra performance level** — 70% floor, ramping to 100% by ~60°C peak zone temp (vs Max's 50% floor and ~68°C). Faster ramp rates and lighter smoothing than Max so cooling reacts earlier when heat builds
- **In-app updates (Sparkle)** — automatic background checks, manual check from Settings, cryptographically signed updates with release notes in the prompt before you accept

## Fixed

- **"No fans detected" no longer flashes when the menu opens** — shows a spinner until the first SMC read completes; fanless Macs still get the real empty-state message
- **Crash after about a month of uptime** — CPU tick counter rollover in the usage graph no longer traps
- **Diagnostics history no longer lost on quit** — log flush completes before process exit
- **Stale XPC connection could tear down its replacement** — late invalidation from an old connection no longer clears the live one
- **The privileged helper now installs correctly** — launch daemon definition is built into the bundle at `Contents/Library/HelperTools` + `Helper3` mach service (SMAppService layout)

## Improvements

- Performance Mode segmented control offers five Cool levels: Low / Medium / High / Max / Ultra
- **Top consumers appear immediately** when detail panels open (CPU and Memory)
- **Diagnostics exports are honest about what wasn't measured** — failed reads are `null`, not `0`; cached fan target/mode values are flagged when not read from hardware
- **Diagnostics record app and helper memory use** — helper footprint reported over XPC
- **Sleep tracking rewritten** — intervals derived from sampling gaps instead of wake notifications
- Loading indicators in panels that fetch data

## After updating

macOS may ask you to approve Fan Sooner's background helper under **System Settings → General → Login Items**. If fan control still does nothing, use **Install Helper** in the Cool menu or re-enable the app under Allow in the Background.

If you used very early ChillMac releases, remove leftover SMJobBless files before restarting:

```
sudo launchctl bootout system/com.idevtim.ChillMac.Helper
sudo rm -f /Library/LaunchDaemons/com.idevtim.ChillMac.Helper.plist
sudo rm -f /Library/PrivilegedHelperTools/com.idevtim.ChillMac.Helper
```

Most recent installs won't need this.
