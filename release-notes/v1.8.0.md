## Highlights

ChillMac updates itself now. When a new version ships you get a prompt in the app — one click downloads it, verifies the signature, installs it and relaunches. No more grabbing a DMG and dragging it over the old copy.

Two things to know about this particular release: you'll need to install it by hand one last time (v1.7.0 has no updater in it to receive this one), and it will ask for your password once on first launch, because the privileged helper changed and has to be re-registered. Every release after this is a single click.

## Added

- **In-app updates** — checks run automatically in the background, and Settings → Check runs one on demand. Updates are cryptographically signed; anything not signed with the ChillMac release key is refused, so a tampered or spoofed download can't install itself. Release notes are shown in the update prompt before you accept
- **Loading indicators** — panels that fetch data now show a spinner while it's on its way instead of an empty list or a blank graph

## Fixed

- **"No fans detected" no longer flashes when the popover opens** — that message was shown during the couple of seconds it takes to read the SMC, before any fan data existed. It now shows a "Reading fans…" spinner and only reports no fans once the read has genuinely completed. Fanless Macs still get the real message
- **Crash after about a month of uptime** — the CPU panel computed usage by subtracting the kernel's tick counters without wrapping. Those counters are 32-bit and roll over after roughly 31 days of uptime, and the rollover would trap rather than produce the correct delta
- **Diagnostics history no longer lost on quit** — the log was flushed to disk asynchronously as the app terminated, and usually lost the race against the process exiting, discarding up to 15 minutes of samples
- **A stale connection to the privileged helper could tear down its replacement** — if an old XPC connection was invalidated after a new one had already been established, it cleared the live one

## Improvements

- **Top consumers appear immediately** — the CPU panel sampled its process list only on every fifth poll, so opening it could mean staring at an empty list for up to 20 seconds. Both the CPU and Memory panels now sample the moment the panel opens
- **Diagnostics exports are honest about what wasn't measured** — failed sensor reads are recorded as `null` instead of `0`, so a fan that stopped and a fan that couldn't be read are no longer indistinguishable in the log. Fan target and mode values reused from cache rather than read from hardware are no longer reported as measurements
- **Diagnostics record ChillMac's own memory use**, and the privileged helper's — which the app can't measure directly, so the helper now reports it over XPC. System-wide memory figures can't reveal a leak in the app itself
- **Sleep tracking rewritten** — sleep intervals are now derived from gaps in sampling rather than paired against wake notifications. Dark wake and Power Nap resume sampling without posting a wake notification, which let a single "sleep" interval stretch across 15 hours that contained hundreds of wide-awake samples
